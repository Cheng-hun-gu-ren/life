# 书籍封面素材说明

本目录用于存放书籍封面图片。

## 📚 命名规范

```
book-{序号}.jpg
```

### 示例
- `book-1.jpg` - 第一本书的封面
- `book-2.jpg` - 第二本书的封面
- `book-3.jpg` - 第三本书的封面

## 🎨 图片规格

### 尺寸要求
- **标准尺寸**：150px × 200px
- **宽高比**：3:4 (书籍标准比例)
- **最小尺寸**：不低于150×200px
- **最大尺寸**：不超过300×400px

### 格式要求
- **文件格式**：JPG
- **色彩模式**：RGB
- **质量**：80-90%压缩质量
- **文件大小**：建议不超过50KB

## 📖 内容要求

### 图片内容
- 使用书籍的官方封面
- 确保封面清晰可读
- 避免有水印或版权标识
- 优先选择高清版本

### 获取来源
- 豆瓣读书
- 亚马逊图书
- 当当网
- 出版社官网

## 🔄 更新说明

- 每次添加新书时，按顺序编号
- 删除书籍时，保持其他编号不变
- 在data/books.json中保持图片路径一致
