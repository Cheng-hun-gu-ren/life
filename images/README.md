# 图片素材说明

本目录用于存放个人生活主页的所有图片素材。

## 📁 目录结构

```
images/
├── avatar-main.png         # 首页大头像 (200x200px)
├── avatar-small.png        # 导航栏小头像 (40x40px)  
├── avatar-card.png         # 侧边栏卡片头像 (120x120px)
├── bg-pattern.svg          # 首页背景装饰图案
├── about-bg.svg            # 关于我背景装饰
├── running-bg.svg          # 马拉松背景装饰
├── books/                  # 书籍封面图片
├── movies/                 # 电影海报图片
├── music/                  # 音乐专辑封面
├── marathon/               # 马拉松相关图片
└── icons/                  # 自定义图标文件
```

## 🎨 通用图片要求

### 格式要求
- **头像**：PNG格式，透明背景
- **背景装饰**：SVG格式，矢量图
- **封面/海报**：JPG格式，高质量
- **图标**：SVG格式，矢量图

### 质量要求
- 分辨率：至少72dpi，推荐150dpi
- 色彩：sRGB色彩空间
- 压缩：保持清晰度的前提下适度压缩

### 风格要求
- 整体风格：清新可爱卡通风格
- 色调：与网站配色方案协调
- 圆角：使用圆角设计，营造温和感觉
