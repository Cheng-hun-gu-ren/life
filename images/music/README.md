# 音乐专辑封面素材说明

本目录用于存放音乐专辑封面和播放列表封面图片。

## 🎵 命名规范

### 专辑封面
```
album-{序号}.jpg
```

### 播放列表封面
```
playlist-{名称}.jpg
```

### 示例
- `album-1.jpg` - 第一张专辑封面
- `album-2.jpg` - 第二张专辑封面
- `playlist-cover.jpg` - 默认播放列表封面
- `playlist-favorites.jpg` - 最爱歌单封面

## 🎨 图片规格

### 尺寸要求
- **标准尺寸**：200px × 200px
- **宽高比**：1:1 (正方形，专辑标准比例)
- **最小尺寸**：不低于200×200px
- **最大尺寸**：不超过500×500px

### 格式要求
- **文件格式**：JPG
- **色彩模式**：RGB
- **质量**：85-95%压缩质量
- **文件大小**：建议不超过80KB

## 🎶 内容要求

### 专辑封面
- 使用官方专辑封面
- 确保图片清晰，无变形
- 避免截图或翻拍
- 优先选择高分辨率版本
- 避免有水印或版权标识

### 播放列表封面
- 可以是专辑封面
- 可以是自制封面（符合整体设计风格）
- 可以是音乐相关的抽象图案
- 保持与网站色彩风格一致

### 获取来源
- Spotify
- Apple Music
- 网易云音乐
- QQ音乐
- 豆瓣音乐
- Last.fm
- 艺人官网

## 🎨 设计建议

### 自制封面要求
- 使用网站配色方案
- 采用可爱卡通风格
- 可加入音符、耳机等音乐元素
- 保持简洁，避免过于复杂

### 色彩搭配
- 主色：薄荷绿 (#4ECDC4)
- 辅助色：天空蓝 (#45B7D1)
- 强调色：温暖橙 (#FFA07A)
- 背景：纯白或极浅薄荷色

## 🔄 更新说明

- 每次添加新音乐时，按顺序编号
- 删除音乐时，保持其他编号不变
- 在data/music.json中保持图片路径一致
- 播放列表封面可以定期更换，保持新鲜感
