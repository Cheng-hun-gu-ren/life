# 电影海报素材说明

本目录用于存放电影海报图片。

## 🎬 命名规范

```
movie-{序号}.jpg
```

### 示例
- `movie-1.jpg` - 第一部电影的海报
- `movie-2.jpg` - 第二部电影的海报
- `movie-3.jpg` - 第三部电影的海报

## 🎨 图片规格

### 尺寸要求
- **标准尺寸**：150px × 225px
- **宽高比**：2:3 (电影海报标准比例)
- **最小尺寸**：不低于150×225px
- **最大尺寸**：不超过300×450px

### 格式要求
- **文件格式**：JPG
- **色彩模式**：RGB
- **质量**：80-90%压缩质量
- **文件大小**：建议不超过60KB

## 🎭 内容要求

### 图片内容
- 使用电影的官方海报
- 优先选择主海报（Main Poster）
- 确保海报清晰，文字可读
- 避免粉丝制作或非官方海报
- 避免有水印或版权标识

### 海报类型优先级
1. **国际版海报** - 设计简洁，质量较高
2. **国内版海报** - 符合国内审美
3. **IMAX版海报** - 质量通常很高
4. **艺术海报** - 设计感强，适合展示

### 获取来源
- IMDb官网
- 豆瓣电影
- 时光网
- 电影官方网站
- 发行公司官网

## 🔄 更新说明

- 每次添加新电影时，按顺序编号
- 删除电影时，保持其他编号不变
- 在data/movies.json中保持图片路径一致
- 定期检查海报质量，及时更换模糊图片
