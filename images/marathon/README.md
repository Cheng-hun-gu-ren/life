# 马拉松相关图片素材说明

本目录用于存放马拉松相关的所有图片，包括证书、奖牌、跑步场景等。

## 🏃‍♂️ 命名规范

### 参赛证书
```
certificate-{赛事简称}-{年份}.jpg
```

### 奖牌照片
```
medal-{赛事简称}-{年份}.jpg
```

### 跑步场景照片
```
scene-{类型}-{序号}.jpg
```

### 示例
- `certificate-shenzhen-2024.jpg` - 2024年深圳马拉松证书
- `certificate-guangzhou-2023.jpg` - 2023年广州马拉松证书
- `medal-shenzhen-2024.jpg` - 2024年深圳马拉松奖牌
- `medal-guangzhou-2023.jpg` - 2023年广州马拉松奖牌
- `scene-race-1.jpg` - 比赛现场照片1
- `scene-training-1.jpg` - 训练场景照片1
- `scene-finish-1.jpg` - 冲线瞬间照片1

## 🎨 图片规格

### 参赛证书
- **标准尺寸**：400px × 300px
- **宽高比**：4:3
- **格式**：JPG
- **质量**：90-95%

### 奖牌照片
- **标准尺寸**：200px × 200px
- **宽高比**：1:1 (正方形)
- **格式**：JPG
- **质量**：85-90%

### 跑步场景照片
- **标准尺寸**：300px × 200px
- **宽高比**：3:2
- **格式**：JPG
- **质量**：80-85%

## 📸 内容要求

### 参赛证书
- 完整的证书内容
- 确保文字清晰可读
- 包含个人姓名、成绩、赛事信息
- 去除个人敏感信息后再使用
- 保持证书的完整性和权威性

### 奖牌照片
- 奖牌正面特写
- 光线充足，细节清晰
- 可以包含背景装饰
- 展示奖牌的设计和质感
- 可以是单独奖牌或多个奖牌组合

### 跑步场景照片
- **比赛现场**：起跑线、赛道、观众、终点等
- **训练场景**：日常训练、晨跑、夜跑等
- **冲线瞬间**：跨越终点线的激动时刻
- **团队合影**：与跑友的合影
- **风景照**：跑步路线的美景

## 🔒 隐私保护

### 个人信息处理
- 模糊处理身份证号
- 遮挡或马赛克个人照片（如需要）
- 隐藏具体的个人成绩（如不愿公开）
- 保留赛事名称和参与年份

### 他人隐私
- 如包含他人照片，需征得同意
- 模糊处理他人面部特征
- 避免包含他人个人信息

## 🏃‍♂️ 展示建议

### 成就展示顺序
1. 最新/最重要的马拉松证书
2. 收藏价值高的奖牌
3. 精彩的跑步瞬间
4. 有纪念意义的场景照片

### 轮播图建议
- 证书类：3-5张最有代表性的
- 奖牌类：按时间顺序或重要性排列
- 场景类：选择视觉效果好的照片

## 🔄 更新说明

- 每次参加新的马拉松后及时添加
- 保持照片的时效性和相关性
- 定期检查图片质量，更换模糊照片
- 在data/marathon.json中保持图片路径一致

## 📝 拍摄建议

### 证书拍摄
- 使用平铺拍摄，避免倾斜
- 确保光线均匀，避免反光
- 保持相机垂直，避免梯形畸变

### 奖牌拍摄
- 使用微距模式突出细节
- 考虑使用简洁背景突出主体
- 可以尝试不同角度展示立体感
